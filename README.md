# 2026 社區消費連環賞小幫手

靜態網頁版個人記錄工具。資料只保存在瀏覽器 localStorage，不與電子錢包同步。

## 本機檢查

在專案目錄啟動任何靜態檔案伺服器，再開啟 `index.html`。核心計算測試位於 `tests/coupon-core.test.js`，使用 Node.js 內建 test runner：

```sh
node --test
```

## 券資料模型

- `government`：政府電子優惠；保留舊資料的 `amount/platform/expiryDate/status` 欄位相容性。
- `merchant_discount`：商戶滿減券；按批次記錄張數 `quantity`、已用張數 `usedCount`、自動有效期及狀態，毋須輸入商戶名稱。
- `merchant_gift`：消費禮遇券；贈品不計入現金節省。

商戶券疊加規則未知時會標示為未知，並排除自動最優計算。規劃方案不會自動核銷或改動記錄。

舊商戶紀錄沒有 `quantity` 時視為 1 張；原有商戶、門檻、優惠、條款、期限及使用狀態保留。毋須搬移或重設 localStorage。新批次只填兩類張數，沿用政府券實際領券日期及補記確認流程，使用同一個 getExpiryISOString 計算下周四澳門時間 23:59:59.999 到期。舊紀錄原有期限（包括未填）不會被猜測或重寫。三類券在同一抽券表登記、同一核銷頁選取後確認才扣券，取消不會改動資料。每次確認有唯一識別碼，防止重複扣券；使用紀錄保存券類、張數及核消時間，全部用完後從持有清單隱藏，原始資料仍保留。

主頁與登記表提供[官方商戶清單及優惠詳情](https://rewards.dsedt.gov.mo/#/website/merchant/index?g=915550)。2026-10-20 已在瀏覽器核實清單可用，列有商戶優惠及「查看更多」完整內容；本工具不複製或推測各商戶優惠。


新增商戶券沿用所選來源 App（`platform`）；首頁及核銷頁按 App 分組，舊資料缺少 App 時顯示「未指定 App」，不修改原始資料。核銷歷史保存 App、券類、張數與澳門時間。統一確認採用快照及唯一 entryId，取消或重複確認不扣券；確認時重新檢查到期狀態。首頁只展示持有資料，政府券方案移到核銷頁。

本工具只記錄已使用，不執行真實核銷。實際用券請到領獎的原 App，按券面及商戶指示操作；不宣稱餘款必須用原 App、不假設各 App 有不同商戶名單或三類券可任意疊加。來源：[澳門政府](https://www.gov.mo/zh-hant/news/1272571/)及[澳門通](https://www.macaupass.com/promotiondetail/1545)。
